# Использование ИИ

При выполнении ПР01 использовался ChatGPT для объяснения работы ROS_DOMAIN_ID,
оформления README и отчёта, проверки команд и анализа результатов.
Команды ROS 2 выполнены в Docker; результаты сохранены в `evidence/pr01`.

При выполнении ПР02 использовался Claude Opus 5.5 для разбора
условия, создания launch-файла и CI, оформления README и отчёта.
Результат проверен сборкой пакета, запуском turtlesim и `check_practice.py PR02`;
выводы команд сохранены в `evidence/pr02`.

При выполнении ПР03 использовался Claude Opus 5.5 для написания ноды `patrol` и тестов,
оформления README и отчёта.
Команды ROS 2 выполнены в Docker; результаты сохранены в `evidence/pr03`.

При выполнении ПР04 использовался Claude Opus 5.5 для добавления параметров в ноду `patrol`,
тестов проверки частоты и ветки с дефектом, оформления README и отчёта.
Команды ROS 2 выполнены в Docker; результаты сохранены в `evidence/pr04`.

При выполнении ПР05 использовался Claude Opus 5.5 для написания нод, оформления README и отчёта.
Команды ROS 2 выполнены в Docker; результаты сохранены в `evidence/pr05`.

При выполнении ПР06 использовался Claude Opus 5.5 для написания модели робота и тестов, оформления README и отчёта.
Команды ROS 2 выполнены в Docker; результаты сохранены в `evidence/pr06`.
